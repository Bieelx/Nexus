## Project Overview

Nexus is a Flutter mobile app focused on digital security, community, and learning. It combines a social timeline, AI chatbot ("Lua" powered by Gemini), security breach monitoring (Have I Been Pwned), educational courses with quizzes, and real-time group chat — all backed by Firebase.

The app is written in Dart, targets Android/iOS/Web/Windows/macOS/Linux, and uses the Firebase project `sec4u-6b6f8`.

## Common Commands

## Architecture

### Navigation

`main.dart` defines `MainNavigation` — an `IndexedStack` with a custom bottom nav bar (`widgets/navbar.dart`) providing 5 tabs: Home, Courses, Leak Check, Community Boards, and Chat (Lua AI).

Auth flow: `AuthCheck` widget in `main.dart` checks Firebase auth state on launch. Unauthenticated users see `LoginPage`; authenticated users see `MainNavigation`.

### State Management

Provider pattern via `AuthService extends ChangeNotifier`. Individual screens use local `StatefulWidget` state. No global state management beyond auth.

### Layer Organization

- **`lib/core/`** — Theme definitions (`app_colors.dart`), auth exceptions, Firebase config, local user ID
- **`lib/models/`** — Data models (e.g., `SecurityEvent`)
- **`lib/service/`** — Business logic services. Key ones:
  - `auth_service.dart` — Firebase Auth + Google Sign-In, user state (Provider-based)
  - `hibp_service.dart` — Have I Been Pwned email breach checking
  - `news_ai_service.dart` — News aggregation + Gemini AI summaries
  - `security_event_service.dart` — Security event logging to Firestore
  - `course_progress_service.dart` / `course_seed_service.dart` — Course tracking and seeding
  - `xp_service.dart` — Gamification (experience points)
  - `gemini_key_service.dart` — Gemini API key management
- **`lib/Screens/`** — Main screens (home, login, chat, boards, courses, leak check, profile)
- **`lib/Screens/Subscreens/`** — Nested views (timeline, groups, lessons, quizzes, rankings)
- **`lib/Screens/Subscreens/Profile/`** — Profile settings pages (email, password, theme, notifications, language, privacy, contact)
- **`lib/widgets/`** — Reusable components (gradient background, leak cards, news feed, forum widgets)

### Firebase / Backend

- **Firestore collections**: `users`, `usernames`, `groups`, `posts`, `courses`, `lessons`, `quiz`, `security_events`
- **Cloud Functions** (`functions/index.js`): Three functions:
  - `checkEmailBreaches` — HIBP proxy (solves CORS for web)
  - `checkEmailPastes` — Paste site checking proxy
  - `callGemini` — Server-side Gemini API calls using Secret Manager for key rotation
- **Auth methods**: Email/Password and Google Sign-In

### AI Integration

Gemini API is used for the "Lua" chatbot (emotional tone: happy, sad, angry, explaining, neutral) and for AI-powered news summaries. Keys are managed via `.env` locally and Firebase Secret Manager in production.

### Styling

Material Design 3 with a dark gradient theme. Custom font: Poppins (400/500/600/700). Centralized color palette in `core/theme/app_colors.dart`. Gradient backgrounds via `widgets/gradient_background.dart`.

## Environment Setup

Requires a `.env` file at project root with:
```
GEMINI_API_KEY=<key>
GOOGLE_SAFE_BROWSING_KEY=<key>
HIBP_API_KEY=<key>
```

Firebase config files needed:
- `android/app/google-services.json`
- `ios/Runner/GoogleService-Info.plist`
- `lib/firebase_options.dart` (auto-generated by FlutterFire CLI)

## Branch Strategy

- **`main`** — Branch principal do app mobile (Android/iOS/Desktop). Todas as features mobile vão aqui.
- **`web-view`** — Branch dedicada para a versão web do projeto (MVP web). Alterações relacionadas ao deploy web, compatibilidade com browser, e Firebase Hosting devem ser feitas nesta branch.

Ao trabalhar em algo relacionado à web, sempre fazer checkout para `web-view`. Ao trabalhar em features do app mobile, usar `main`.

### Web Deploy (branch `web-view`)

```bash
git checkout web-view
flutter build web
firebase deploy --only hosting --project sec4u-6b6f8
```

URL de produção: https://sec4u-6b6f8.web.app

#### Limitações da versão web
- Push notifications desabilitadas (guard `kIsWeb` em `firebase_messaging_service.dart`)
- Speech-to-text indisponivel
- Imagens usam `Uint8List` (bytes) em vez de `dart:io.File`
- Google Sign-In requer `clientId` OAuth configurado em `auth_service.dart` e meta tag em `web/index.html`
- Firestore: acessar campos com `doc.data()['campo']` em vez de `doc['campo']` (web lanca excecao se o campo nao existir)
